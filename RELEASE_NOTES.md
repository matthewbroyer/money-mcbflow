# Release notes · money.mcbflow.com

## 1.7 · 2026-10-16
- New Settings page, in the same order as the other mcbflow.com apps: Appearance (light or dark, Simple or Full Dashboard), Account & sync, Money settings (your details), the Essential Banking Checklist, Backup & data, Install and About. On phones it is the first item under More.
- New Help page with getting set up, quick answers, release notes, privacy and terms (they used to sit at the bottom of Settings).
- New account button in the top bar, next to the light/dark switch: "Sign in", or your initial with a green, amber or red sync dot. "Keep me signed in on this device" can be turned off on a shared computer.
- New welcome screen on your first visit, the same as in the other apps: a short tour of the main pages, light or dark, then the 2-minute snapshot, demo data or an empty start, with Sign in to sync and Import a backup for people moving from another device. It replaces the separate "Your data stays here" note.
- Clearer Data menu: each item says what it's for, in the same order as the other apps. New Export All (ZIP) puts the JSON backup, the full CSV and one spreadsheet each for transactions, budgets and balances in one file. Import Backup takes that ZIP too. Year-end summary and Paste transactions are in the menu as well.
- Quieter backup reminders while you're signed in and syncing: no amber backup warnings; the backup chip reads "Synced".
- Charts: every bar, line, dot and progress bar shows a label when you hover, tap or use the arrow keys, with the value first; the other bars fade while you read one. Bars have 4px rounded tops, targets are dashed and labelled (the savings rate chart now shows the 20% target), and the net worth sparkline can be read month by month.
- Even top bar: every control is the same height. The name now reads "Money ∙ mcbflow.com" on computers and "Money" on phones.
- Each page ends with the same short footer as the other apps (What's new, Privacy, Terms, More free apps, "Not financial advice.").
- Profile picture and screen name: sign in, then Edit profile to pick one of 20 pictures and the name the apps call you. The account button and the Settings card show your picture, the same in every mcbflow.com app.
- Home greets you by the time of day ("Good morning, Matthew"), using your screen name when you're signed in or the name in Settings when you're not. It replaces the "Welcome, <name>!" title, so there is only one greeting.
- Dashboard is now called Home, with a house icon, to match the phone tab and the other apps (page title, sidebar, browser tab "Money | Home"). Settings has a real gear icon, and Help and More use the standard icons.
- Your data, backups and settings are unchanged. Old backups and CSV files still import. Old #start links open Settings and old #dashboard links open Home.

## 1.6.1 · 2026-10-15
- Fixed: loading demo data while signed in to sync could remove synced transactions from your account. Demo data now needs you to sign out first, and sync pauses safely while demo data is showing.

## 1.6 · 2026-10-15
- New: optional sync across devices. Data → Sync across devices signs in with a free mcbflow.com account; budgets, balances, transactions, subscriptions, goals and settings then match on every device you sign in on.
- Transactions sync month by month, so long histories stay quick.
- Everything still saves on this device first and works offline. Not signed in: nothing changes, and no server is contacted. Demo data never syncs.
- Clear all data warns when you're signed in, since it also clears synced data.

## 1.5 · 2026-10-14
- Moved to money.mcbflow.com. Data saved at the old address doesn't carry over: export a backup there and import it here.
- Storage names simplified.

## 1.4 · 2026-10-14
- On computers, the search box, backup status and logo spacing now look exactly like the other mb apps: same size, same "Search…" text and the same "/" shortcut.
- The top bar now looks and works the same as in the other mb apps: Search, Data and the light/dark switch sit in the same places with the same icons. On phones they are square icon buttons next to the logo.
- Transactions on phones: the Select all box and the Date / Description / Amount sort buttons sit in one tidy row that lines up with your transactions and stays under the top bar while you scroll.
- The sort buttons on Transactions can now be used with the keyboard (Tab, then Enter).
- Your data, backups and settings are unchanged.

## 1.3 · 2026-10-14
- About card at the bottom of Settings: version, release date, links and copyright in one place.
- Installing from matthewbroyer.com: the hub's Install button opens the app with a short install prompt.
- New "page not found" page that matches the app and links back to it.
- The Install card moved to the bottom of Settings, just above the About card.

Earlier releases (ALPHA, April 2024 through BETA 4.7, October 13, 2026) are listed in the app under Settings → Release notes. The "Official Web App" brand line read v1.1 at BETA 4.6 and v1.2 at BETA 4.7.
